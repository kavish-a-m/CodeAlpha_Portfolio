## 💻 How to Run Locally

### Option 1: Direct Browser Launch (Zero Dependencies)
Because this project is built entirely with vanilla web standards, you can open `index.html` directly in any modern browser:
1. Double-click `index.html`, or
2. Right-click `index.html` → **Open With** → **Google Chrome** / **Edge** / **Firefox**.

### Option 2: Using VS Code Live Server (Recommended)
1. Open the project folder in VS Code.
2. Click **Go Live** in the status bar or right-click `index.html` → **Open with Live Server**.
3. Access at `http://127.0.0.1:5500/index.html`.

### Option 3: Built-in Python HTTP Server
```bash
python -m http.server 5500
```
Open `http://localhost:5500` in your web browser.

## 🌐 Deployment to GitHub Pages

1. Navigate to the repository settings on GitHub: [github.com/kavish-a-m/CodeAlpha_Portfolio](https://github.com/kavish-a-m/CodeAlpha_Portfolio).
2. Go to **Settings** → **Pages** (in the left sidebar).
3. Under **Build and deployment** → **Branch**, select `main` and root folder `/`.
4. Click **Save**. Your live portfolio will be deployed at:
   ```text
   https://kavish-a-m.github.io/CodeAlpha_Portfolio/
   ```
